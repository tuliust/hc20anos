# Roadmap — registro histórico da fase inicial

> [!WARNING]
> Este documento preserva o planejamento inicial do produto. Não representa o estado atual nem o backlog vigente. Algumas funcionalidades listadas como futuras, incluindo Mercado Pago e e-mails transacionais, já possuem implementação no repositório.
>
> Para compreender o produto vigente, consulte [`00-visao-geral/produto.md`](./00-visao-geral/produto.md). O trabalho de documentação e reconciliação está organizado no Epic #41.

## MVP planejado

- Landing page.
- Ingressos.
- Checkout visual.
- Supabase.
- Admin.
- Base de ex-alunos.
- Mural de fotos.
- Reivindicação de perfil.
- Check-in.

## Fase 2 planejada

- Curtidas.
- Comentários.
- Memórias.
- Enquetes.
- Mapa/lista “Onde a turma está hoje”.
- Convite compartilhável.
- Meu ingresso real.

## Fase 3 planejada

- Mercado Pago real.
- E-mails transacionais.
- WhatsApp.
- Relatórios avançados.
- Múltiplos eventos.
- Produto reutilizável para reencontros.

## Fora do escopo declarado na época

- Rede social completa.
- Chat entre ex-alunos.
- Reconhecimento facial.
- App mobile nativo.
- Pagamento real sem credenciais/back-end seguro.

## Uso permitido

Este arquivo pode ser usado para reconstruir a evolução do escopo e comparar intenção inicial com o produto atual. Ele não deve ser usado para decidir se uma funcionalidade está implementada, ativa, segura ou pronta para produção.
